# SQL Practice

## 📌 Overview
This repository contains a collection of beginner-friendly SQL practice queries covering the fundamental concepts of SQL. It is designed to help learners understand database creation, table management, data insertion, and data retrieval using different SQL clauses.

## 💻 How to Run

1. Open MySQL Workbench or any MySQL-compatible SQL editor.
2. Open the `SQL_Practice.sql` file.
3. Execute the script.
4. The script will:
   - Create the database `data_analyst`
   - Create the required tables
   - Insert sample records
   - Execute practice SQL queries

---

## 🎯 Learning Objectives

After completing this script, you will understand:

- Creating databases and tables
- Inserting records
- Retrieving data using SELECT
- Using aliases
- Filtering data with WHERE
- Applying comparison operators
- Using logical operators (AND, OR, NOT)
- Using the IN operator
